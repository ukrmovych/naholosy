# Статистика і відгуки без Google Analytics

Сторінка: **https://ukrmovych.duckdns.org/gym/stats/** (захищена паролем, у пошуковиках не з'являється).

## Що зробити один раз

1. Supabase → **SQL Editor → New query** → вставити весь [`stats.sql`](stats.sql) → **Run**.
2. Унизу, у результаті, з'явиться **пароль** (12 символів). Скопіюй його.
3. Відкрий сторінку статистики, введи пароль. Браузер його запам'ятає.

Забув пароль? Запусти в SQL Editor: `select password from public.stats_access;`
Змінити: `update public.stats_access set password = 'новий-пароль';`

## Що показує сторінка

За сьогодні / 7 / 30 / 90 днів:
- **люди**: скільки гравців (пристроїв), нових, тих, хто повертався в різні дні, скільки відкриттів гри і яка частка — з Telegram;
- **по днях**: гравці й розпочаті ігри;
- **ігри**: марафони (середній рахунок, рекорд), тренування (і скільки дійшли до кінця), дуелі, хто пройшов усі слова, хто записався в таблицю;
- **найпопулярніші групи тренувань**, дуелі на 2/3/4 гравці;
- **онлайн-режими**: створені/початі/дограні кімнати, гравців у середньому, запрошення;
- **яких ігор чекають** — кліки на ігри з позначкою «скоро»;
- **о котрій грають** (київський час);
- **турнірна таблиця**: скільки людей у ній по кожній грі.

Гра не збирає імен чи особистих даних — лише випадковий ідентифікатор пристрою.
Дані пишуться з моменту запуску `stats.sql`; давніші є тільки в Google Analytics.

Технічно: гра пише події в таблицю `game_events` (лише додавання), а сторінка
отримує готові підсумки через функцію `get_stats`, яка без пароля нічого не віддає.

## Відгуки

У меню гри є блок **«💬 Залиш відгук»**: оцінка (5 смайликів), текст із підказками, хто пише
(учень / вчитель / батьки), підпис і галочка «можна показати іншим». У Telegram можна ще дозволити
написати людині (тоді збережеться її нік).

Щоб відгуки зберігалися: Supabase → **SQL Editor → New query** → вставити [`feedback.sql`](feedback.sql) → **Run**.
Читати — на тій самій сторінці `…/stats/`, вкладка **«💬 Відгуки»**: фільтри «лише ті, що можна публікувати»
і «лише з оцінкою 4–5», кнопка **«Скопіювати»** дає готову цитату: `«текст» — ім'я`.

## Ігри для класу

Після кожної гри для класу (у будь-якій темі) її підсумки — нікнейми учнів, бали, кількість правильних
відповідей, дата й час — зберігаються в Supabase. Щоб це працювало, один раз запусти
[`class-results.sql`](class-results.sql) (SQL Editor → New query → Run).

Переглядати — на сторінці `…/stats/`, вкладка **«🏫 Класи»**: кожна гра розгортається в таблицю,
кнопка «⬇️ Завантажити таблицю» дає файл для Excel / Google Таблиць.
Учитель також одразу після гри може завантажити або скопіювати таблицю результатів.
