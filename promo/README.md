# promo/ — картки й відео-гайди з інтерфейсом гри

Не викладається на сервер (виключено в `deploy.yml`). Результати й проміжні файли (`out/`, `work/`) — не в git.

Запуск: `bash promo/make.sh` (усе) або `bash promo/make.sh video` (лише відео). Потрібні: Playwright (Chromium у `/opt/pw-browsers/chromium`), ffmpeg, python3 + numpy + Pillow. Гра відкривається локально на `http://localhost:8765/` (скрипт сам запускає сервер із кореня репозиторію). Мережа до Supabase не потрібна: усі запити до бази підмінені вигаданими даними.

## Файли
- `shots.js` — знімки для карток (телефон 390×844, ×3). Тут вигадані учні класу «11-Б» (`FULL`, `LEKS`; серед них «бос нмт», «676767», «чаша жиру») і підміна запитів (`page.route`).
- `card.html` + `cards.js` — картки 1080×1350 (помаранчевий фон, шрифт Balsamiq, телефон зі знімком). Тексти карток — у `cards.js`.
- `capture.js` — повні знімки сторінок для відео (`work/v/shots`) + координати кнопок (`work/v/meta.json`). Набір тексту знімається по буквах (`cA1…`, `cB1…`, `iA1…`).
- `compose.html` — «монтаж» відео 1080×1920: функція `render(t)` малює кадр у момент t. Сценарій угорі: `SHOTS` (екрани, прокрутка, переходи push/fade/zoom), `CAPS` (підписи «Крок N»), `TAPS` (куди «тицяє пальчик»), `CURSOR_ON`, `RINGS` (підсвітка), `SPARKS` (іскри), `DURATION`. Звуки ставляться самі за подіями (`ev(...)`).
- `render.js` — знімає кадри 30 fps у `work/v/frames` (`node render.js 5,12.3` — лише окремі секунди для перевірки → `work/v/check-*.jpg`).
- `audio.py` — фонова музика (синтезована, без авторських прав) + клацання, клавіші, «вжух», дзвіночки за подіями → `work/v/audio.wav`.
- `make.sh` — усе разом; ffmpeg склеює кадри й звук у `out/myclass-guide-video.mp4`.

Якщо змінився інтерфейс: селектори кнопок — у `capture.js`/`shots.js` (напр. картка «Створити клас» — `.class-card:nth-child(3)`), часи сценарію — у `compose.html`.
