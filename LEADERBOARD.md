# Турнірна таблиця: як підключити (≈5 хвилин)

Сайт на GitHub Pages — це лише файли, тому результати гравців зберігаються
в безкоштовній базі **Supabase**. Поки її не підключено, гра працює як звичайно,
а в таблиці написано «скоро запрацює».

## 1. Створити базу

1. Зареєструватися на <https://supabase.com> (можна через GitHub).
2. **New project** → придумати назву й пароль → регіон, наприклад, *Central EU (Frankfurt)*.
3. Зачекати 1–2 хвилини, поки проєкт створиться.

## 2. Створити таблицю

1. Ліворуч **SQL Editor** → **New query**.
2. Вставити весь вміст файлу [`leaderboard.sql`](leaderboard.sql) і натиснути **Run**.

## 3. Вписати ключі в гру

1. **Project Settings** → **API** (або **Data API** / **API Keys**).
2. Скопіювати **Project URL** і ключ **anon public**.
3. Відкрити [`leaderboard-config.js`](leaderboard-config.js) і вставити їх:

```js
window.LEADERBOARD_CONFIG = {
  url: "https://abcdefgh.supabase.co",
  anonKey: "eyJhbGciOi..."
};
```

Ключ **anon public** призначений саме для сайту, його можна тримати у відкритому коді.
**Не вставляй** ключ `service_role` / `secret` — він дає повний доступ до бази.

## Як видалити ім'я (матюки, реклама)

1. Supabase → **Table Editor** → таблиця **scores**.
2. Відмітити рядок(-и) галочкою → **Delete**.

Гра вже сама не пропускає імена з посиланнями, `@`, довгими числами
й найпоширенішими лайливими словами, але хитрі варіанти все одно варто
прибирати вручну.

## Що варто знати

- Гравці не можуть змінювати чи видаляти чужі записи — лише додавати свої.
- Технічно вміла людина може надіслати вигаданий результат напряму в базу,
  оминувши гру. Для шкільної гри це нормальний компроміс; підозрілі записи
  (наприклад, 99999) просто видаляй так само, як і погані імена.
