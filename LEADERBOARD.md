# Турнірна таблиця: як підключити (≈5 хвилин)

Сайт на GitHub Pages — це лише файли, тому результати гравців зберігаються
в безкоштовній базі **Supabase**. Поки її не підключено, гра працює як звичайно,
а в таблиці написано «скоро запрацює».

## 1. Створити базу

1. Зареєструватися на <https://supabase.com> (можна через GitHub).
2. **New project** → придумати назву й пароль → регіон, наприклад, *Central EU (Frankfurt)*.
3. Зачекати 1–2 хвилини, поки проєкт створиться.

## 2. Створити таблицю

1. Ліворуч **SQL Editor** → **New query**.
2. Вставити весь вміст файлу [`leaderboard.sql`](leaderboard.sql) і натиснути **Run**.

## 3. Вписати ключі в гру

1. **Project Settings** → **API** (або **Data API** / **API Keys**).
2. Скопіювати **Project URL** і ключ **anon public**.
3. Відкрити [`leaderboard-config.js`](leaderboard-config.js) і вставити їх:

```js
window.LEADERBOARD_CONFIG = {
  url: "https://abcdefgh.supabase.co",
  anonKey: "eyJhbGciOi..."
};
```

Ключ **anon public** призначений саме для сайту, його можна тримати у відкритому коді.
**Не вставляй** ключ `service_role` / `secret` — він дає повний доступ до бази.

## Як видалити ім'я (матюки, реклама)

1. Supabase → **Table Editor** → таблиця **scores**.
2. Відмітити рядок(-и) галочкою → **Delete**.

Гра вже сама не пропускає імена з посиланнями, `@`, довгими числами
й найпоширенішими лайливими словами, але хитрі варіанти все одно варто
прибирати вручну.

## Що варто знати

- Гравці не можуть змінювати чи видаляти чужі записи — лише додавати свої.
- Технічно вміла людина може надіслати вигаданий результат напряму в базу,
  оминувши гру. Для шкільної гри це нормальний компроміс; підозрілі записи
  (наприклад, 99999) просто видаляй так само, як і погані імена.

# Речення для «Лексичної помилки»

Речення **не лежать у коді сайту**. Вони зберігаються в закритій таблиці
`sentences` у тому ж проєкті Supabase, і гра отримує їх по одному через
функцію `random_sentence`. Прочитати таблицю цілком через сайт не можна.

## Як завантажити речення (один раз)

1. Supabase → **SQL Editor** → **New query** → вставити вміст
   [`sentences.sql`](sentences.sql) → **Run**.
2. Нова вкладка → вставити `sentences-part1.sql` → **Run**.
3. Нова вкладка → вставити `sentences-part2.sql` → **Run**.

Файли `sentences-part1.sql` і `sentences-part2.sql` — це сама база речень.
**Не додавай їх у репозиторій.** Тримай у себе.
`sentences-part1.sql` спершу очищує таблицю, тож обидві частини можна
запускати повторно без дублів (саме в такому порядку: 1, потім 2).

## Як додати, змінити чи видалити речення

Supabase → **Table Editor** → таблиця **sentences**:

- **Insert → Insert row**: нове речення. Формат той самий, що й раніше:
  слова з помилкою в зірочках (`*слово*`), наприкінці `✅-помилок-немає-✅`
  (у зірочках, якщо помилок немає).
- Подвійний клік на клітинці: виправити.
- Галочка біля рядка → **Delete**: видалити.
- Щоб речення траплялося частіше, додай його ще раз окремим рядком.

## Чесно про захист

- Звичайний гравець не може скопіювати текст, виділити його чи відкрити
  контекстне меню, а вся база одним файлом із сайту не скачується.
- Людина з інструментами розробника все одно бачить кожне речення, яке
  їй показали, і теоретично може зібрати базу скриптом, граючи
  без кінця. Повністю захистити текст, який показуєш у браузері, неможливо.
